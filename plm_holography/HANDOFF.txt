1. SHORT MEETING SUMMARY

I have built a standalone simulation library for 4-bit phase PLM holography,
extending the single-frame ASM phase-optimization workflow to RGB, multiple
depths and temporal integration. It supports independent, fixed-group joint,
whole-sequence global and fixed-history causal optimization. Both window length
W and stride S are configurable. Phase quantization and an optional known-eye-
motion model are implemented, and saved results can be independently reproduced.

The current achievement is a working, tested simulation framework. A complete
dynamic-quality comparison, measured hardware calibration and full-resolution
validation are still pending. The next research step is a controlled comparison
of global and causal W8/S4 optimization, followed by quantization and eye-motion
experiments. This is Holospeed-inspired work, not a complete paper reproduction.

2. IMPLEMENTED CAPABILITIES

- Differentiable padded ASM with configurable wavelengths, pixel pitch, depths,
  crop, numerical aperture, cached kernels and FFT-consistent frequency grids.
  One phase pattern produces fields at all three depths; it is not a separate
  independently chosen phase for each depth.
- Static/dynamic monochrome or RGB focal-stack targets from synthetic scenes,
  numerical NPZ arrays or image manifests. Image loading explicitly decodes sRGB.
  Existing demonstrations use synthetic targets, not measured scene datasets.
- Exposure-weighted temporal INTENSITY integration. Complex fields and
  amplitudes are never summed across separate exposures. Brightness gains are
  fixed; there is no automatic brightness fitting.
- Four temporal optimization methods, Adam or plain SGD, and intensity MSE or
  amplitude MSE after intensity integration. SGD is an optimizer, not a loss.
- Continuous phases, continuous optimization with hard-quantized checkpoint
  selection, hard-forward STE, and a custom smooth-gradient surrogate.
  Replaceable 16-state per-color phase LUTs support nonuniform/nonmonotonic
  responses while preserving physical code IDs.
- Optional supplied/synthetic 2D eye translations. Target and reconstruction
  undergo the same alignment and integration, with shared valid-pixel masks.
- Saved phases/codes, embedded inputs/LUTs, reconstructions, losses, MSE/PSNR,
  temporal errors, fixed-scale previews, propagation counts and runtime.
  Evaluation reconstructs the saved state in a fresh Python process.

3. AGREED WINDOW MODEL

W and S count complete RGB cycles. At the default 1440 physical PLM updates/s,
W=8 means eight patterns per color: 24 exposures spanning about 16.67 ms.
Playback order is G,R,B. Default source gains are 3 per color to compensate
the one-third duty cycle in simulation; these are not measured laser powers.

For W=8, S=4, windows cover cycles 1–8, 5–12 and 9–16:
- Causal: optimize the first 24 phases jointly, then only 12 new phases per
  block. Previously committed phases stay fixed. Each new block's targets must
  be available before displaying it; this is buffered/offline block planning.
- Global: optimize all 48 phases together using the selected window endpoints.
  It has access to the whole target sequence and does not commit blocks.

Every method is evaluated at every physical endpoint, including intermediate
ones. Full windows are the main quality metric; startup is reported separately.
An omitted/null stride advances optimization at every physical exposure, while
integer S=1 advances one RGB cycle (three exposures). They are different modes.

Current research entry points:
configs/sliding_w8_s4_causal.json
configs/sliding_w8_s4_global.json
Both specify 64x64, 48 phases, three depths, 200 updates per phase, gain 3 and
motion disabled. Their full quality runs are pending. The base lab profile still
uses global optimization with null stride; its defaults were not changed.

5. WHAT "14 OF 24 BENCHMARK RUNS" MEANS

This is an experiment count, NOT a count of implemented or missing features:
2 scenes (static/moving) x 3 initial seeds (0/1/2) x 4 methods = 24 runs.
Each uses 64x64 phases, three depths, 48 RGB exposures, a 24-exposure integration
window and 200 optimizer updates per phase. Methods share initialization and
targets within each scene/seed group, with fixed optics and gains.

Completed: all 12 static runs, plus moving seed0 independent and joint.
Pending: moving seed0 global/causal and all four methods for moving seeds1/2.
The 14 completed runs have matched initial/target hashes within each group and
19,296 phase propagations per run. There is no complete benchmark report yet.

IMPORTANT: this older benchmark has motion OFF and NULL stride. It is not the
later W8/S4 experiment. Its completed final MSE values are approximately 0.19–0.21;
convergence and quality need further investigation. Do not claim that causal
optimization, sliding windows or the custom quantizer already outperform baselines.
Historical runtimes overlapped other jobs and are not isolated speed measurements.

二、目前有什么

传播：可微 padded ASM、FFT 一致频率、旧网格对照、核缓存、裁剪、可选 NA；
逐颜色波长/逐深度传播。单位照明振幅，phase-only。
输入：单色/RGB、静态/动态多深度线性光强；合成场景、NPZ、图像清单，
sRGB 解码、时间插值。演示是合成场景，没有真实场景实验数据集。
时序：默认 GRB、1440 次物理曝光/s，每色 8 张=24 次曝光≈16.67 ms。
RGB 固定增益默认每色 3，是模拟占空比补偿，不是测量激光功率。
曝光加权累积光强，不跨时间叠加复振幅，不自动匹配亮度。
算法：independent / joint / global / causal；Adam 或普通 SGD；强度 MSE
或积分后取平方根的振幅 MSE。SGD 是优化器，不是 loss。
量化：16 状态，圆周最近距离，保留物理 code，支持非均匀/非单调 LUT。
眼动：可关闭，或给定/合成二维轨迹；对齐后积分，共享有效区域掩码。
输出：配置、环境、输入哈希、相位/code、原始/积分重建、loss、MSE/PSNR、
时间误差、固定范围图像、GIF、传播计数和耗时；新进程独立重算。

三、窗口规则与当前入口

用户已接受按块因果规则：历史固定，不增加重优化已提交历史的模式。
W、S 以 RGB 周期计；单色一个周期就是一次曝光。W8/S4 第一块优化 24 张，
之后每块优化 12 张新相位，重叠历史冻结。是离线/缓冲后的按块规划，

求平均 loss，不逐块提交。所有模式最终评价每个物理端点，完整窗口为
主指标，启动单列。
