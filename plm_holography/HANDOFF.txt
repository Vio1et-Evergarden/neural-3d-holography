schedule.stride_cycles=null (or omitted) preserves the original per-physical-frame
behavior. An integer 1<=S<=window_cycles uses RGB/mono cycle units, starts at the
first full window, and includes a shortened final step when needed. For W=8,S=4,
causal first jointly solves cycles 1-8, then freezes history and solves new cycles
9-12, then 13-16. Global jointly updates the whole sequence using those window
endpoints. Evaluation still covers every physical exposure. Block-causal planning
requires each new block's targets before displaying that block.
